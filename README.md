# **Num R'n'R**

**Num R'n'R** は、Windows 環境において接続されたキーボードごとに NumLock 状態を個別に保持し、操作対象の装置に応じて自動で状態を同期するユーティリティ アプリケーション。

Numlockと踊れ。

## **概要および特徴**

* **システム トレイ常駐型アプリケーション**  
  * タスク トレイに常駐し、バックグラウンドで状態を監視・同期。  
  * アイコン表示により、現在の NumLock 状態をリアル タイムに視覚確認可能。  
* **キーボード個体別の NumLock 状態保持**  
  * Raw Input API (WM\_INPUT) で VID / PID を識別し、キーボードごとの NumLock 状態を記憶。  
* **装置切り替え時の自動同期**  
  * キーボードが切り替わった際、直前に記録された NumLock 状態へ即座に復元。  
* **コントロール パネルによる状態可視化**  
  * 認識された装置の識別情報、保持状態 (画面上では最大 8 台まで表示)、動作ログを表示。

## **基本仕様および動作環境**

### **1\. 動作環境**

* **対応 OS**: Windows 10 / Windows 11  
* **ランタイム**: .NET Framework 4.8  
* **ターゲット アーキテクチャ**:  x86  
* **利用条件**: 特になし (MIT License の下、自己責任のもと無償かつ自由に利用可能)

### **2\. ファイル構成および役割**

実行ファイル (numrnr.exe) と同一ディレクトリに固定名称で自動生成・参照される。

```
.  
├── numrnr.exe             \# 実行ファイル  
├── .numrnr.config         \# システム設定ファイル (XML 形式)  
└── numrnr.properties      \# NumLock 状態保存データ (Key-Value 形式)
```

| データ種別 | ファイル名 (numrnr.exe の場合) | 形式 | 役割 |
| :---- | :---- | :---- | :---- |
| **システム設定** | .numrnr.config | XML 形式 | 動作モードなどの設定情報 |
| **NumLock 状態データ** | numrnr.properties | Key-Value 形式 (VID\_XXXX\&PID\_YYYY=true 等) | キーボードごとの NumLock 状態保存データ |


### **3\. 制限事項および免責事項**

1. **初回入力時の反映遅延**  
   * キーボードの識別は切り替え後の 1 打鍵目を検知して行うため、装置切り替え直後の初回入力時に1打鍵分の反映遅延が生じる仕様。  
2. **サイン イン画面およびロック画面**  
   * Windows のサインイン画面およびロック画面 (Winlogon 対話セッション) では動作不可。

## **使用方法 (基本操作)**

### **1\. 起動と常駐化**

* `numrnr.exe` を実行するとシステム トレイにアイコンが表示され、常駐状態となる。  
* 継続運用のため、ショート カットを作成してスタート アップ フォルダ (`shell:startup`) へ配置することを推奨。

### **2\. コントロール パネルの操作**

* トレイ アイコンのダブル クリック、または右クリック メニューの Control Panel で表示。  
* `Numlock State Memories`: 認識中のキーボードとそれぞれの NumLock 状態を表示。直近の操作デバイスには `=>` を表示。  
* `Activity Logs`: 識別や状態同期の処理ログをリアル タイム表示。

### **3\. メニュー項目一覧**

* `File` \> `Minimize:` コントロール パネルを最小化し、トレイに格納。  
* `Mode` \> `Sync Numlock LastState on Keybord Chaged`: 装置切り替え時の自動同期の有効 / 無効化。  
* `Mode` \> `Update State`: 状態記憶更新の有効 / 無効化 (無効時は 🔏 マーク表示)。  
* `View` \> `Top Most`: コントロール パネルの最前面表示。  
* `Debug` \> `Toggle Numlock`: 手動で NumLock 状態を反転。  
* `Help` \> `About`: バージョン情報の表示。

## **使い方例 (応用・設定パターン)**

### **1\. 動作 モードの切り替え**

コントロール パネルの Mode メニューから動作変更が可能。

* `Sync Numlock LastState on Keybord Chaged`:
  * **有効 (初期値)**: 入力がキーボード切り替え時、記録していたNumlock状態を復元する。
* `Update State`:  
  * **有効 (初期値)**: 入力に応じてキーボードごとのNumLock状態を随時を更新 (記録)。
  * **無効 (記憶の固定化)**: 状態更新を停止 (記録停止)。

### **2\. プロパティ ファイル読み取り専用化による状態固定**

キーボード切り替え時に常に特定の NumLock 状態を維持したい場合、`numrnr.properties` を読み取り専用化することで状態を固定可能。

**固定化の手順:**

1. `numrnr.properties` に各装置の希望状態 (例: `VID_XXXX&PID_YYYY=true`) を記述。  
2. ファイル属性を「読み取り専用」に設定。  
3. アプリ終了時のファイル上書き保存が防止され、起動時および切り替え時に常に特定の NumLock 状態へ復元可能。

## **開発およびビルド環境**

### **1\. 開発・ビルド環境条件**

* **ターゲット フレームワーク**: .NET Framework 4.8  
* **Widget toolkit**: Windows Forms (WinForms)  
* **使用言語**: C\# 8.0  
* **ターゲット アーキテクチャ**: x86

### **2\. ビルド実行**

```
# デバッグ ビルド  
dotnet build -c Debug

# リリース ビルド  
dotnet build -c Release
```

### **3\. アプリケーション実行**

```
dotnet run -c Release
```

### **4\. 配布パッケージ生成 (パブリッシュ)**

```
dotnet publish -c Release -o ./publish
```

### **5\. クリーン**

```
dotnet clean
```
